## Agent skills

### Issue tracker

Issue 與規格以 GitHub Issues（sweetMochi/lyric-flyer）追蹤，透過 `gh` CLI 操作。See `docs/agents/issue-tracker.md`.

### Triage labels

使用 5 個預設 triage label：`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：根目錄 `GLOSSARY.md` + `docs/adr/`。See `docs/agents/domain.md`.
