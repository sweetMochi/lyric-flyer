# 振假名以行內標記存於歌詞檔，不在執行期自動產生

振假名寫在歌詞行文字中，語法為 `{漢字|かな}`，以詞為單位整組標註（熟字訓如 `{今日|きょう}` 不拆字）。播放頁只負責解析與顯示，不載入任何詞法分析字典。執行期以 kuroshiro 加 kuromoji 自動產生的方案被否決：字典約十幾 MB，且多音字與歌詞特殊讀法（如「宿命」讀作「さだめ」）必然出錯。第一階段振假名全由人工標註，第二階段才在編輯器中以 lazy load 的 kuromoji 產生草稿供人工修正

羅馬拼音預設由「假名原文加振假名讀音」以 wanakana 轉換，不需字典；歌詞行可用 `ro` 欄位手動覆寫

## Considered Options

- **結構化片段陣列（`segments: [{t, r}]`）**：Schema 能驗證到每個片段，但手寫極為冗長，而第一階段歌詞檔全靠手寫

## Consequences

- Schema 只能以 regex 檢查標記格式，細部錯誤由匯入時的解析器回報
- 有漢字未標振假名的歌詞行無法自動轉換羅馬拼音，該行不顯示羅馬拼音，並於匯入時給出警告
- wanakana 會把助詞「は」「を」「へ」轉為 `ha`、`wo`、`he`，需靠 `ro` 覆寫修正
