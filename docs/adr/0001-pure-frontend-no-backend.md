# 純前端、不設後端，資料只存在瀏覽器與匯出檔

本專案是單人使用的 PWA，部署於 GitHub Pages 等靜態主機，不使用任何伺服器、Serverless 或 BaaS（如 Firebase）。工作資料存於瀏覽器本機儲存，使用者自行保管的歌曲庫檔才是正本，跨裝置同步一律透過匯出與匯入完成。如此可完全免除帳號、主機與費用，代價是瀏覽器資料可能被清除，因此必須提供完整的歌曲庫檔匯出與取代匯入

## Consequences

- 任何需要密鑰的外部 API 都無法安全使用，見 [0002](./0002-iframe-api-and-oembed-only.md)
- 路由採 hash 模式，避免靜態主機重新整理時回傳 404
