# 歌曲以 UUID 識別，同一支影片可對應多首歌曲

歌曲的唯一鍵是書籤樹中歌曲節點的 UUID（`crypto.randomUUID()`），不另外建立獨立的歌曲實體；videoId 只是歌曲的一個可修改屬性，且允許重複。最初曾以 videoId 作為唯一鍵，但「替換影片」會改變 videoId，連帶需要搬移儲存 key、改寫所有參照，並使 `#/play/` 連結失效。改以 UUID 後，替換影片只需更新欄位，第二階段的播放序列等功能也能穩定參照歌曲

## Consequences

- 同一 videoId 的多首歌曲各自擁有歌詞、時間差與名稱，互不連動
- 「無法播放」屬於影片，因此標記與清除時會同步更新所有同 videoId 的歌曲
- 新增或替換成已存在的影片時只提示、不阻擋
- 歌詞檔帶有可能為空值的 `id`：匯出時必定寫入，手寫時可省略。第一階段單首匯入只以 `id` 比對既有歌曲，`id` 未命中一律新增；以 videoId 比對的「覆蓋、新增、略過」三選一留待第二階段
